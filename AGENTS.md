# The Advisor Game - Agent Instructions

Before changing code:

1. Read the relevant project documentation.
2. Read the relevant GitHub issue.
3. Inspect the existing implementation.
4. Prefer the smallest compliant change.
5. Do not modify unrelated systems.

During implementation:

- Follow existing architecture.
- Preserve naming conventions.
- Do not delete unrelated code.
- Do not modify generated artifacts unless required.
- Keep changes scoped to the current issue.

Validation:

- Run relevant tests.
- Inspect git diff.
- Report all changed files.
- Report tests executed.
- Report failures or unresolved risks.
- Always clean/remove test files and previous versions after successful validation.
