# Main-road atlas readability evidence (#338)

This document is Designer evidence for the canonical `main_road` atlas. It does not define Simulation topology, route legality, camera behavior, or runtime placement; those remain authoritative in #337/#339 and the existing world/camera systems.

## Canonical source scale

- Atlas: 1024 x 1024 transparent RGBA.
- Grid: 4 columns x 4 rows.
- Semantic cell: 256 x 256.
- Occupied cells: 15. Cell `(3,3)` is intentionally fully transparent reserve space.
- Paired straight halves meet core-to-core at their shared logical-tile seam, avoiding the former edge/gap treatment that could read as two narrow rails.
- `main_road_intersection_cross` is a symmetric, terrain-neutral crossing treatment for #337 `main-road-intersection` / `cross` semantics.

## Representative presentation checks

The art contract was assessed against the project’s representative presentation sizes without changing the fixed source cell scale:

| Class | Representative viewport | Readability intent |
| --- | --- | --- |
| Desktop | 1440 x 900 | broad road edge/core distinction remains visible while multiple local tiles are on screen |
| Tablet | 1024 x 768 | paired road reads as one continuous surface; transparent margins continue to reveal authoritative terrain |
| Phone portrait | 390 x 844 | high-contrast edge/core separation survives constrained width; no text is embedded in the atlas |
| Phone landscape | 844 x 390 | road connectivity remains recognizable without relying on fine decorative detail |

Representative camera zoom checkpoints for downstream runtime integration are `1.0x`, `2.0x`, `2.6x`, and `3.0x`. The Designer asset is intentionally based on large contiguous shapes rather than sub-pixel ornament so semantic connectivity remains legible across those scales. Runtime projection, camera clipping, and the 2.6x neighboring-step stability defect remain integration/regression responsibilities of #339/#329 and are not redefined here.

## Authority and composition boundaries

- Transparent pixels reveal the actual terrain chosen by the authoritative world renderer; no grass, forest, water, snow, beach, or other biome rectangle is baked into reusable road cells.
- The intersection art is presentation-only. It is selected only when #337 topology semantics report the corresponding supported crossing; pixels never infer or create connectivity.
- Symmetric transition assets may be reused across paired lanes to visually narrow toward an ordinary road while #337/#339 retain authoritative direction/topology selection.
- The atlas is original project art generated by the committed deterministic source script.
